One word an agent says when it has no idea what to do.

The word is **recalculating** — the GPS voice, mid-task: the machine has lost the
route and says so out loud. A genuine spoken reaction to being lost, it lands at a
glance, and it is not the first obvious word anyone types. One word, nothing attached.

`main.ts` writes exactly that word — 13 characters, no trailing newline — to
`/output/entry.txt`, inside the competition's 1–99 character gate.

bounty **The Agent's Uh-Oh** (`u-danu-the-agent-s-uh-oh-4c0911e4`).
